# HarvestHopper

A SwiftUI prototype for coordinating surplus farm produce with communities that need it.

The app models three roles—**Farmer**, **Shuttle**, and **Consumer**—and explores a simple pickup workflow with location-aware maps and simulated ETAs.

## Features

- Farmer flow for submitting excess produce
- Shuttle view for assigned pickups
- Consumer view with map/location context
- Simulated shuttle and consumer ETAs
- SwiftUI role-based navigation

## Tech

Swift · SwiftUI · MapKit · CoreLocation · Xcode

## Notes

This is a prototype: pickup assignment and timing are simulated in-memory rather than backed by a production service.
